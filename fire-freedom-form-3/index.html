How this form works

This is a static form, so it does not send responses to a server by itself. A simple no-backend form can still let users complete fields and download their answers as a local file from the browser, which is a practical option for lightweight sharing.[web:98][web:104]

Use the Save Draft button while filling it out, then use Export Answers when finished. Group members can send the exported file back to you through WhatsApp, Dropbox, or email.
