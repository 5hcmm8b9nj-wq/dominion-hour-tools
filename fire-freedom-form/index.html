Google Sheet setup

Google Apps Script can be deployed as a web app, and an HTML form can send data to that web app so the script writes each submission into a Google Sheet.[web:116][web:120]

For this method to work correctly, the column headers in the sheet should match the form field names you want to collect, and the Apps Script web app should be deployed with access that allows form submissions.[web:116][web:118]

Example Apps Script functions usually use a deployed web app URL and receive form data with a POST request, then append the values to the next open row in the sheet.[web:116][web:121]

Apps Script code

Apps Script web apps use functions such as doPost(e) to receive submitted data and can append that data into a Google Sheet row by row.[web:120][web:118]

Paste this into Extensions → Apps Script inside your Google Sheet, replace YOUR_SHEET_NAME, then deploy as a web app with access set so your group can submit.[web:116][web:120]

function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName('YOUR_SHEET_NAME');
  var data = JSON.parse(e.postData.contents);

  sheet.appendRow([
    new Date(),
    data.participant || '',
    data.groupName || '',
    data.weekOf || '',
    data.mainTheme || '',
    data.d1pp || '',
    data.d1pk || '',
    data.d1words || '',
    data.d1testimony || '',
    data.d2authority || '',
    data.d2theme || '',
    data.d2ignite || '',
    data.d2testimony || '',
    data.d3truth || '',
    data.d3area || '',
    data.d3mind || '',
    data.d3relations || '',
    data.d3ministry || '',
    data.d4decl || '',
    data.d4personal || '',
    data.d4scripture || '',
    data.d4reflection || '',
    data.d5vision || '',
    data.d5identity || '',
    data.d5ministry || '',
    data.d5family || '',
    data.d5health || '',
    data.d5spirit || '',
    data.d6strategy || '',
    data.d6targets || '',
    data.flame1 || '',
    data.flame2 || '',
    data.flame3 || '',
    data.d7lifechange || '',
    data.d7confirm || '',
    data.d7belief || '',
    data.d7doing || '',
    data.d7testimony || '',
    data.d7scripture || '',
    String(data.track1done || false),
    String(data.track2done || false),
    String(data.track3done || false),
    String(data.track4done || false),
    String(data.track5done || false),
    String(data.track6done || false),
    String(data.track7done || false)
  ]);

  return ContentService
    .createTextOutput(JSON.stringify({ result: 'success' }))
    .setMimeType(ContentService.MimeType.JSON);
}
